# Notice to Vacate Guide

A comprehensive guide to notice to vacate letters, 
covering all 50 US states' legal requirements.

## What is a Notice to Vacate?

A notice to vacate is a formal letter used by landlords or tenants to communicate the intent to end a lease. 
Requirements vary significantly by state — notice periods range from 7 to 60 days depending on jurisdiction.
